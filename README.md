# Lab-GH300

This project contains a simple Python dashboard for tracking daily sports exercise.

## Features
- Add workout entries with date, sport, duration, calories, intensity, and notes
- View daily and weekly trends
- See total minutes, calories, and recent workout history
- Save data locally in a CSV file for easy reuse

## Run locally
1. Create a virtual environment if needed
2. Install dependencies:
   pip install -r requirements.txt
3. Start the app:
   streamlit run app.py

The app stores data in the `data/exercise_log.csv` file.
